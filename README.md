# Repositorio PISA Matemáticas · Julio Verne School

Aplicación educativa HTML con **84 actividades y 167 preguntas**, organizada por bloques matemáticos. Incluye seis situaciones adicionales de la colección de práctica PISA 2025.

## Publicación en GitHub Pages

1. En GitHub, crea un repositorio nuevo llamado `jvs-repositorio-pisa` (o el nombre que prefieras).
2. Sube **`index.html`** y **`.nojekyll`** a la raíz del repositorio. No subas el ZIP: descomprímelo primero.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama **main** y la carpeta **/(root)**; guarda los cambios.
6. Espera a que GitHub Pages publique el sitio. La dirección será similar a `https://TU-USUARIO.github.io/jvs-repositorio-pisa/`.

## Actualizar la aplicación

Sustituye `index.html` por una versión nueva, manteniendo el mismo nombre. GitHub Pages publicará el cambio automáticamente.

## Uso

Abre la URL publicada desde cualquier navegador o compártela en Microsoft Teams. La aplicación está empaquetada en un solo HTML y no requiere servidor de aplicaciones.

## Nota

Antes de distribuirla al alumnado, revisa las advertencias del solucionario sobre las situaciones incorporadas y comprueba la visualización en tu dispositivo.
